# Encapsulamento

Esta pasta aborda o encapsulamento, um dos princípios fundamentais da Programação Orientada a Objetos, utilizado para controlar o acesso aos dados de uma classe.

**Conteúdos:**
- Modificadores de acesso (`public`, `private` e `protected`)
- Atributos privados
- Métodos getters e setters
- Validação de dados
- Proteção e controle do estado dos objetos
- Métodos para adicionar e remover dados de um objeto

**Objetivo:** criar classes mais seguras, organizadas e com controle sobre seus próprios dados.
