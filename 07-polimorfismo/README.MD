# Polimorfismo

Esta pasta reúne os estudos sobre polimorfismo, um princípio da POO que permite utilizar uma mesma referência ou operação com diferentes comportamentos.

**Conteúdos:**
- Conceito de polimorfismo
- Sobrescrita de métodos
- Upcasting e downcasting
- Polimorfismo com herança
- Uso de métodos sobrescritos
- Exemplos práticos

**Objetivo:** entender como diferentes objetos podem responder de maneiras distintas a uma mesma chamada de método.
