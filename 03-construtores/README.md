# Construtores

Esta pasta reúne os estudos sobre construtores, utilizados para inicializar objetos no momento de sua criação.

**Conteúdos:**
- Conceito de construtor
- Construtor padrão
- Construtores com parâmetros
- Inicialização de atributos
- Sobrecarga de construtores
- Uso de `this` para diferenciar atributos de parâmetros

**Objetivo:** aprender a criar objetos com seus dados iniciais definidos corretamente.
