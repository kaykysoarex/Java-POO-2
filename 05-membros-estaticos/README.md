# Membros Estáticos

Esta pasta reúne os estudos sobre membros estáticos, que pertencem à classe e não a uma instância específica de um objeto.

**Conteúdos:**
- Palavra-chave `static`
- Atributos estáticos
- Métodos estáticos
- Diferenças entre membros estáticos e de instância
- Acesso a membros estáticos
- Exemplos práticos de utilização

**Objetivo:** entender quando utilizar membros que são compartilhados pela classe.
