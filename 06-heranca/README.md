# Herança

Esta pasta apresenta o conceito de herança na Programação Orientada a Objetos, permitindo que uma classe aproveite características e comportamentos de outra.

**Conteúdos:**
- Conceito de herança
- Superclasse e subclasse
- Palavra-chave `extends`
- Reutilização de atributos e métodos
- Palavra-chave `super`
- Sobrescrita de métodos com `@Override`

**Objetivo:** compreender como estabelecer relações entre classes e reutilizar código de maneira organizada.
