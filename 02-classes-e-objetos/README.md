# Classes e Objetos

Esta pasta apresenta os fundamentos da Programação Orientada a Objetos (POO), mostrando como representar elementos do mundo real por meio de classes e objetos.

**Conteúdos:**
- Conceito de classe e objeto
- Atributos e métodos
- Instanciação de objetos com `new`
- Acesso aos membros de uma classe
- Separação de classes em arquivos
- Organização por pacotes (`package` e `import`)

**Objetivo:** compreender como criar classes e utilizar objetos para organizar o código.
